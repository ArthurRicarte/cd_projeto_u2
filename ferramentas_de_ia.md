Citando as tecnologias de IA que utilizamos para auxiliar na produção do projeto da U2.

## Claude Code
#### `Explorar Tabelas`: Fazer leituras sobre as estruturas das tabelas e apontar os principais campos que podiamos usar para trabalhar.
- `Validação`: Já haviamos validado as tabelas antes para ver quais os campos/colunas que poderiamos utilizar, vimos se as analises do Claude batiam com as observações dos campos também.
#### `Auxílio na Criação de 'coleta.ipynb'`: Nos ajudou a criar a rotina para fazer o download das tabelas .csv que nós não sabiamos fazer e ajudou também para validar o nosso código, apontar erros e melhorias.
